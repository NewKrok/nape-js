Warum nape-js?

nape-js ist eine der wenigen 2D-Physik-Engines für JavaScript und TypeScript, die Starrkörperdynamik, Gelenke (PivotJoint, DistanceJoint, WeldJoint, AngleJoint, MotorJoint, LineJoint, PulleyJoint, SpringJoint), Auftrieb in Flüssigkeiten, Fraktur, Soft Body, Raycasting und konvexe Sweeps, einen integrierten Character Controller, deterministisches Stepping für Multiplayer-Rollback, binäre Serialisierung, Replay-Aufzeichnung und eine Web-Worker-Bridge außerhalb des Hauptthreads mitbringt — alles in einem einzigen tree-shakeable ESM-Bundle (~27 KB gzip), mit vollständigen TypeScript-Typen und ohne DOM-Abhängigkeiten.

Suchst du eine Alternative zu Box2D, Matter.js, Planck.js oder Rapier? Führe den Benchmark im Browser aus, um sie direkt zu vergleichen, oder stürze dich in die interaktiven Beispiele — Physik-Demos und spielbare Mini-Games (Platformer, MOBA, Tower Defense, Slingshot, Pinball, Top-Down-Shooter).

Die API auf einen Blick

Kern

  • Space — Physikwelt
  • Body — Starrkörper
  • Vec2 — 2D-Vektor
  • AABB — Begrenzungsrahmen

Shapes

  • Circle — radiusbasiert
  • Polygon — konvexe Hülle
  • Capsule — abgerundete Enden
  • Polygon.box(w, h)

Constraints

  • PivotJoint
  • DistanceJoint
  • WeldJoint
  • AngleJoint
  • MotorJoint
  • LineJoint
  • PulleyJoint

Callbacks

  • InteractionListener
  • BodyListener
  • ConstraintListener
  • PreListener
  • CbType + CbEvent

¿Por qué nape-js?

nape-js es uno de los pocos motores de física 2D para JavaScript y TypeScript que incluye dinámica de cuerpos rígidos, juntas (PivotJoint, DistanceJoint, WeldJoint, AngleJoint, MotorJoint, LineJoint, PulleyJoint, SpringJoint), flotabilidad de fluidos, fractura, cuerpo blando, raycasting y barridos convexos, un controlador de personaje integrado, avance determinista para rollback multijugador, serialización binaria, grabación de repeticiones y un puente Web Worker fuera del hilo principal — todo en un único paquete ESM apto para tree-shaking (~27 KB gzip), con tipos TypeScript completos y cero dependencias del DOM.

¿Buscas una alternativa a Box2D, Matter.js, Planck.js o Rapier? Ejecuta el benchmark en el navegador para compararlos cara a cara, o entra directo a los ejemplos interactivos — demos de física y mini-juegos jugables (plataformas, MOBA, tower defense, resortera, pinball, shooter cenital).

La API de un vistazo

Núcleo

  • Space — mundo físico
  • Body — cuerpo rígido
  • Vec2 — vector 2D
  • AABB — caja envolvente

Formas

  • Circle — basada en radio
  • Polygon — envolvente convexa
  • Capsule — extremos redondeados
  • Polygon.box(w, h)

Restricciones

  • PivotJoint
  • DistanceJoint
  • WeldJoint
  • AngleJoint
  • MotorJoint
  • LineJoint
  • PulleyJoint

Callbacks

  • InteractionListener
  • BodyListener
  • ConstraintListener
  • PreListener
  • CbType + CbEvent
